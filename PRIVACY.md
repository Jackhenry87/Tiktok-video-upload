# Privacy Policy — TikTok Videos (personal automation tool)

_Last updated: July 2026_

1. **Who this covers.** This app is a single-user, personal-use tool. It connects only to its owner's TikTok account. It has no other users and collects no data from anyone else.
2. **What it stores.** OAuth tokens for the owner's TikTok account, video files the owner creates, and posting metadata (captions, schedules, upload results). All of it is stored locally in the owner's own database and file storage.
3. **What it shares.** Nothing. Data is sent only to TikTok's official API for the purpose of publishing the owner's own posts. No analytics, no advertising, no third-party data sales.
4. **Data deletion.** The owner can delete all stored data at any time by deleting the local database and storage directories, and can revoke the app's access in TikTok settings.
5. **Contact.** Questions: open an issue on this repository.
